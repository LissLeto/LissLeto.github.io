# Galliard Web Fonts

These files were supplied from the site owner's local font installation and
copied without modification. Both are served as the CSS family `Galliard Web`.

| File | Original Full Name | CSS Style |
| --- | --- | --- |
| `Galliard-Roman.otf` | GalliardRoman | normal, 400 |
| `Galliard-Italic.otf` | GalliardITCbyBT-Italic | italic, 400 |

The original copyright notices embedded in the files are:

- Roman: Copyright Copr.1992 Image Club Graphics, Inc.
- Italic: Copyright 1990 as an unpublished work by Bitstream Inc. All rights reserved. Confidential.

These are commercial fonts, not part of the open-source Source Han Serif
distribution. Neither file includes a webfont license notice. The font's
technical embedding flag (`fsType = 0`) is not evidence of a webfont license.
Confirm that the site's font license covers web embedding and public
distribution before publishing the font files.

Licensing reference: https://www.myfonts.com/collections/galliard-font-itc

The regular and italic files are preloaded. `font-display: swap` keeps text
visible during loading. Chinese body text continues to use Source Han Serif.
