# Source Han Serif Web Font

This directory includes Adobe's official Simplified Chinese region-specific
variable web font, distributed under the SIL Open Font License 1.1.

- File: `SourceHanSerifCN-VF.woff2`
- Upstream file: `SourceHanSerifCN-VF.otf.woff2` (renamed without modification)
- Source: https://github.com/adobe-fonts/source-han-serif/tree/release
- Download: https://raw.githubusercontent.com/adobe-fonts/source-han-serif/release/Variable/WOFF2/OTF/Subset/SourceHanSerifCN-VF.otf.woff2
- License: `SourceHanSerif-LICENSE.txt`
- Weight range: 200-900

The font is served by this website, so visitors do not need to install it.
Body text prefers Times New Roman for Latin characters and uses this font for
Chinese characters. `font-display: swap` allows text to remain visible while
the font downloads. Keep the license with the font when redistributing it.
